# 翻訳キーを削除するリソースパック
  このリソースパックよりも下にあるリソースパックの翻訳キーをほぼ全て削除します。

  `chat.type.admin`や`options.generic_value`等、特に利用する可能性の大きい翻訳キーは[再追加](#再翻訳している翻訳キー)しています。

# 注意事項
  1.19以降で動作すると思いますが、`pack.mcmeta`の記述の制限により推奨バージョンは1.20以降になっています。

  なお、`pack_format`をメインに利用しているバージョンでの動作確認はしておりません☆彡
  
# 即知のバグ
  リソースパックロード時、不明なキーを`rename`しようとしてエラーが出る。
